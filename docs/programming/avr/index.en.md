    ### 2. PlatformIO Installation
    The easiest way to program the microcontroller is with [PlatformIO](https://platformio.org/) in Visual Studio Code. Here is a short video tutorial:

    <figure class="video_container">
    <video controls="true" allowfullscreen="true">
        <source src="../../assets/videos/win_install_vscode_pio.mp4" type="video/mp4">
    </video>
    </figure>

    As shown in the video, please install [Visual Studio Code](https://code.visualstudio.com/).
    In Visual Studio Code, then install the `PlatformIO` extension.

    Please note that installing the extension can take a long time and requires a restart of VSCode at the end.

=== "Linux"

    Install the `platformio` package to be able to compile the firmware.

    As a development environment, [VS Code](https://code.visualstudio.com/docs/setup/linux) is recommended.
    It offers good integration with the `platformio` plugin, but any other editor will also work.

    An overview of programming examples and how to run them can be found [here](examples.md).
