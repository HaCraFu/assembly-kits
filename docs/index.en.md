## Programming

[Bau(m)satz](kits/baumsatz.md) and [Unicorn](kits/unicorn.md) can be programmed by yourself. On Windows, you must first [follow these steps](programming/avr/index.md).

Then download [our source files](https://github.com/HaCraFu/assembly-kits/archive/refs/heads/main.zip) and extract them.

You can now [try existing example programs](programming/avr/examples.md) or develop your own programs.
