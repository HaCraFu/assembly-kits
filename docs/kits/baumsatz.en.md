# Bau(m)satz

<img src="../kibot/baumsatz/render/baumsatz-3D_top.png" width="200" height="200" alt="Bau(m)satz Front">
<img src="../kibot/baumsatz/render/baumsatz-3D_bottom.png" width="200" height="200" alt="Bau(m)satz Back">

This circuit board is mostly based on the [Digistump](http://digistump.com/wiki/digispark/tutorials/connecting).
It also contains the microcontroller [ATtiny85](https://ww1.microchip.com/downloads/en/DeviceDoc/Atmel-2586-AVR-8-bit-Microcontroller-ATtiny25-ATtiny45-ATtiny85_Datasheet.pdf) and the USB circuit.

In addition to the Digistump, 6 LEDs are connected to PB0, PB1 and PB2 via [Charlieplexing](https://en.wikipedia.org/wiki/Charlieplexing).

It can therefore be programmed in the same way.
